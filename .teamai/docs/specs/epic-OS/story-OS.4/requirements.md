**版本:** v1.0

## 1. 功能概述

### 1.1 产品目标

提供类似 macOS Spotlight 或 Raycast 的全局命令面板，让用户通过快捷键快速搜索和启动系统功能。

### 1.2 核心价值

| 价值点 | 描述 |
|-------|------|
| **快速访问** | 单一入口快速触达所有功能 |
| **键盘优先** | 完整键盘导航，无需鼠标 |
| **智能搜索** | 模糊匹配，容错性强 |
| **多类型结果** | 应用、命令、Agent 一站式搜索 |
| **流畅交互** | 打开/关闭动画流畅自然 |

## 2. 用户角色

| 角色 | 权限 | 使用场景 |
|-----|------|---------|
| **普通用户** | 使用 Spotlight | 快速打开应用、执行命令 |
| **高级用户** | 使用快捷键 | 提高操作效率 |
| **开发者** | 搜索Agent、调试 | 快速启动开发工具 |

## 3. 功能需求

### 3.1 快捷键触发 ✅

**需求**: Cmd/Ctrl + K 打开/关闭 Spotlight

**功能**:
- 全局快捷键监听
- Cmd+K (Mac) / Ctrl+K (Windows/Linux)
- 重复按键关闭
- Esc 键关闭

**验收**:
- [ ] 快捷键正确触发
- [ ] 重复按键关闭
- [ ] Esc 键关闭

### 3.2 搜索框 ✅

**需求**: 顶部搜索框，自动聚焦

**功能**:
- 自动聚焦
- 实时输入
- 占位符提示 "Search..."
- 清除按钮 (x)

**验收**:
- [ ] 打开时自动聚焦
- [ ] 输入实时显示
- [ ] 清除按钮工作正常

### 3.3 结果列表 ✅

**需求**: 显示匹配的搜索结果

**功能**:
- 多类型结果 (应用/命令/Agent)
- 图标 + 标题 + 描述
- 结果高亮（匹配关键词）
- 滚动展示（最大 N 条）

**验收**:
- [ ] 至少 3 种结果类型
- [ ] 图标正确显示
- [ ] 搜索关键词高亮
- [ ] 滚动流畅

### 3.4 键盘导航 ✅

**需求**: 完整键盘导航控制

**功能**:
- 方向键 ↑↓ 选择结果
- Enter 执行选中项
- Esc 关闭面板
- Tab 切换焦点

**验收**:
- [ ] ↑↓ 键选择结果
- [ ] Enter 执行命令
- [ ] Esc 关闭面板
- [ ] Tab 导航可用

### 3.5 模糊搜索 ✅

**需求**: 容错性强的模糊匹配

**功能**:
- 部分匹配（输入 "dev" → "Developer"）
- 错别字容忍（输入 "dvlpr" → "developer"）
- 优先级排序（匹配度高的结果在前）

**验收**:
- [ ] 部分匹配正确
- [ ] 错别字容忍
- [ ] 排序合理

## 4. 用户场景

### 场景 1: 启动应用

```
用户按 Cmd+K
    ↓
Spotlight 打开，搜索框聚焦
    ↓
输入 "finder"
    ↓
显示 " Finder" (应用图标)
    ↓
按 Enter
    ↓
打开应用，Spotlight 关闭
```

### 场景 2: 启动 Agent

```
用户按 Cmd+K
    ↓
输入 "dev"
    ↓
显示 "Developer Agent" (💻)
    ↓
按 Enter
    ↓
开发者 Agent 状态变为 RUNNING
    ↓
打开 Agent 对话窗口
```

### 场景 3: 执行系统命令

```
用户按 Cmd+K
    ↓
输入 "set"
    ↓
显示 "Settings" (⚙️)
    ↓
按 Enter
    ↓
打开设置面板
```

## 6. 界面需求

### 6.1 布局

```
┌─────────────────────────────────────────┐
│  🔍 Search...                     x    │  ← 搜索框
├─────────────────────────────────────────┤
│  📄  Finder               ↵ ⌘F         │  ← 应用
│  💻  Developer Agent      ↵ ⌘D         │  ← Agent
│  ⚙️  Settings              ↵ ⌘,         │  ← 命令
│  🎨  UX Designer Agent     ↵ ⌘U         │  ← Agent
│  ...                                     │
│  ─────────────────────────────           │
│  5 results  ↑↓ navigate  ↵ select       │  ← 底部提示
└─────────────────────────────────────────┘
```

### 6.2 尺寸规范

| 元素 | 尺寸 | 说明 |
|-----|------|------|
| 最大宽度 | 600px | 响应式居中 |
| 最大高度 | 500px | 结果区域 |
| 结果项高度 | 48px | 单行结果 |
| 搜索框高度 | 44px | 顶部区域 |

### 6.3 动画

**打开动画**:
- transform: scale(0.95 → 1)
- opacity: 0 → 1
- duration: 150ms
- easing: cubic-bezier(0.16, 1, 0.3, 1)

**关闭动画**:
-反向打开动画

**选中动画**:
- backgroundColor 渐变
- duration: 150ms

## 7. 数据需求

### 7.1 搜索项数据结构

```typescript
interface SpotlightItem {
  id: string;           // 唯一标识
  type: 'app' | 'command' | 'agent';  // 结果类型
  title: string;        // 显示标题
  subtitle?: string;    // 副标题
  icon: string;         // emoji 图标
  shortcut?: string;    // 快捷键提示
  action: () => void;   // 执行动作
  keywords?: string[];  // 搜索关键词
}
```

### 7.2 数据源

| 数据源 | 类型 | 说明 |
|-------|------|------|
| Dock Apps | app | 来自 OS.2 Dock |
| Agent Registry | agent | 来自 OS.3 Agents |
| System Commands | command | 系统操作 |

## 8. 集成需求

### 8.1 与 Desktop 集成 (OS.1)

- 作为 overlay 渲染在 Desktop 上层
- z-index 高于其他组件

### 8.2 与 Agent Registry 集成 (OS.3)

- 实时读取 Agent 列表
- 同步 Agent 状态到搜索结果

### 8.3 与 Dock 集成 (OS.2)

- 搜索 Dock 中的 Apps
- 启动 App 时更新 Dock 状态
