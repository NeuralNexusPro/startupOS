# SENSE.13 交互设计

```text
首页应用启动器                  顶部系统栏
┌──────────────────────┐       📡●
│ 📡 感知与连接         │         └─ 连接状态快速面板
│ 接收邮箱和企业消息     │            ├─ 总体状态
│ 自动交给 Agent 处理    │            ├─ 各连接摘要
└──────────────────────┘            └─ 管理感知中心
           └──────────────▶ 感知中心单例窗体
```

卡片承担发现与启动，状态按钮承担日常监控，通知承担“发生了什么”。卡片位于工作区之后；移除原整行横幅。

沿用首页深色玻璃体系和 Tailwind 预设：`blue-600` 主色，`green-600/yellow-600/red-600` 表达健康。唯一签名元素是雷达图标旁的健康脉冲点，减少动态偏好下静止。文案使用“感知与连接”“连接正常”“需要处理”，不展示 webhook、transport、secretRef。

面板支持 Esc/点击外部关闭并恢复触发器焦点；窄屏限制在视口内。状态必须同时使用文字、图标和 `aria-label`，不只依赖颜色。
