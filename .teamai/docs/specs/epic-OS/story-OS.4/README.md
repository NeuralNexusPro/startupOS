# Story OS.4: Spotlight 全局命令

**状态:** Design In Progress
**优先级:** High
**估计工时:** 3-4 天
**调度:** Week 2, Days 1-4

---

## 用户故事

> 作为用户，我希望通过快捷键快速打开全局命令面板，这样我能快速搜索和启动功能。

---

## 功能需求

### 核心功能
- **快捷键触发**：Cmd/Ctrl + K 打开/关闭
- **搜索框**：顶部聚焦，实时搜索
- **结果列表**：显示匹配的应用、命令、Agent
- **键盘导航**：方向键选择，Enter 执行，Esc 关闭
- **模糊搜索**：支持部分匹配

### 交互流程

```
快捷键 (Cmd+K) → Spotlight 打开
              → 搜索框聚焦
              → 输入关键字
              → 实时显示结果
              → 方向键选择 / Enter 执行
              → Esc 关闭
```

---

## 验收标准

- [ ] Cmd/Ctrl + K 快捷键可打开/关闭
- [ ] 搜索框自动聚焦
- [ ] 搜索结果实时更新（< 100ms）
- [ ] 键盘导航可用
- [ ] 模糊搜索正确匹配（至少 3 种结果类型）
- [ ] 动画流畅（打开/关闭）
