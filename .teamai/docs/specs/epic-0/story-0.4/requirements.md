# 需求文档 - Story 0.4

**Story:** 意图理解与路由
**Epic:** Epic 0 - 技术架构实施层
**最后更新:** 2026-03-04

---

## 📋 用户故事

作为用户，
我可以使用自然语言描述需求，
系统通过 LLM 理解我的意图并自动调用相应的能力。

---

## 🎯 功能需求

### FR0.4.1: 意图理解

- 使用 LLM 解析用户消息
- 识别用户的真实意图
- 提取关键参数

### FR0.4.2: 能力路由

- 根据意图选择合适的工具
- 多工具协调执行
- 执行结果汇总

### FR0.4.3: 意图澄清

- 当意图不明确时主动询问
- 提供上下文相关的澄清问题
- 支持多轮对话完善需求

---

## ✅ 验收标准

### AC0.4.1: 简单意图路由

**Given** 用户说"创建一个名为'用户管理'的本体实体"
**When** 系统处理消息
**Then** 调用 create_ontology 工具
**And** 参数正确填充

### AC0.4.2: 多工具协调

**Given** 用户说"创建用户实体，然后添加认证关系"
**When** 系统处理消息
**Then** 按顺序执行两个工具
**And** 第二个工具使用第一个的结果

### AC0.4.3: 意图澄清

**Given** 用户说"创建概念"
**When** 系统检测缺少参数
**Then** 主动询问概念名称和类型

---

## 📊 意图分类

| 意图类别 | 示例表达 | 对应工具 |
|---------|---------|---------|
| 文件操作 | "读取文件"、"保存" | read_file, write_file |
| 本体操作 | "创建实体"、"添加关系" | create_ontology_node, add_relation |
| 查询操作 | "查找概念"、"列出所有" | query_ontology, list_files |
| 编辑操作 | "修改文本"、"删除节点" | write_file, delete_ontology_node |
