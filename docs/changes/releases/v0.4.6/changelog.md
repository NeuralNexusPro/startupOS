# Changelog - v0.4.6

本版本修复历史记忆较多的角色打开后主进程持续占用 CPU、窗口无响应的问题，并修复桌面顶部时间在服务端渲染与客户端水合跨分钟时引发的页面替换。

## 2026-10-09 — fix：历史角色记忆检索不再卡死

**类型**：fix

**影响模块**：Memory Core、Role Agent、Desktop 开发运行时

**摘要**：修正 HNSW 贪心搜索在邻接节点之间循环的问题，为扩展搜索增加去重与访问上限；启动时恢复已持久化的向量索引，避免首次检索重新计算全部历史记忆。开发启动现在会刷新并固定解析到当前编译的 Core runtime，防止打包残留使 `desktop:dev` 继续加载旧代码。

## 2026-10-09 — fix：桌面时间水合一致性

**类型**：fix

**影响模块**：Web 桌面顶部菜单

**摘要**：服务端与客户端首次渲染使用稳定的时间占位符，挂载后再启动时钟，避免跨分钟时出现 `Text content does not match server-rendered HTML` 并替换整棵页面树。
