# OriginOS CE v0.2.4

发布日期：2026-09-17

## IM 平台能力

- Agent 可以按需发现并调用企业微信、飞书和钉钉插件声明的办公能力；能力调用沿用当前 IM 连接的授权身份，并记录可审计的调用结果。
- 企业微信接入官方能力提供器，并支持手机端消息附件进入 OriginOS 会话与工作目录。
- 企业微信收到消息后可先显示处理中状态，再由正式回复更新原消息。

## Agent 与 Skill 会话

- 历史会话标题从实际对话内容提炼，旧会话在读取列表时自动更新；过滤问候、继续执行和通用操作词，优先保留可区分会话的主题。
- Agent 与 Skill 打开历史列表时主动刷新，避免继续显示旧的重复标题。

## 感知中心

- 能力目录和调用记录通过现有 Plugin Host、授权与生命周期边界管理，不在 Core 中逐项硬编码平台 SDK。
- 修正配置表单刷新期间的平台选择保持行为。

## 验证

- Core、企微、飞书、钉钉专项回归与架构边界检查通过。
- Windows、macOS arm64 和 macOS x64 安装包由 Desktop Release 工作流构建、校验并发布。
