## 1. 设计概述

### 1.1 设计目标

让 Dock 的交互体验接近 macOS Dock：
- 简洁优雅的悬停放大
- 自然流畅的拖拽排序
- 直观的右键菜单
- 清晰的运行状态指示

### 1.2 设计原则

| 原则 | 实施 |
|-----|------|
| **Glassmorphism** | Acrylic 半透明材质 |
| **简洁优雅** | 底部居中，不遮挡内容 |
| **状态感知** | 实时显示应用运行状态 |
| **流畅优先** | 60fps 稳定动画 |

### 1.3 设计参考

- **macOS Dock**: 悬停放大、拖拽排序、右键菜单
- **Fluent Design**: Glassmorphism 材质、Fluent 动画
- **Windows 11 Taskbar**: 固定底部、居中对齐

## 2. 交互流程

### 2.1 初始加载流程

```
用户打开 OriginOS
    ↓
Desktop 空间加载 (fade in 0.3s)
    ↓
Dock 从底部滑入 (slide up 0.4s)
    ↓
图标依次淡入 (staggered 0.1s)
    ↓
完成初始化，等待用户交互
```

### 2.2 悬停放大流程

```
鼠标悬停在图标上
    ↓ [mouseenter]
图标缩放: 1.0x → 1.2x (scale 0.2s)
    ↓
Tooltip 淡入 (fade in 0.15s)
    ↓
鼠标移开
    ↓ [mouseleave]
图标缩放: 1.2x → 1.0x (scale 0.2s)
    ↓
Tooltip 淡出 (fade out 0.15s)
```

### 2.3 点击启动应用流程

```
用户点击图标
    ↓ [click]
图标按下反馈 (scale 0.95)
    ↓
图标恢复 (scale 1.0x)
    ↓
应用启动中 (指示灯闪烁)
    ↓
应用启动完成
    ↓
图标下方显示绿色指示灯
```

### 2.4 拖拽排序流程

```
用户按住图标
    ↓ [mousedown]
图标抓取效果 (scale 1.1, shadow 增强)
    ↓ [dragging]
移动时跟随鼠标，位置更新
    ↓
经过其他图标位置时，其他图标平滑移开 (translate 0.15s)
    ↓ [mouseup]
如果在新位置：
    ↓
吸附到新位置 (snap 0.2s)
    ↓
图标顺序更新
```

### 2.5 右键菜单流程

```
用户右键点击图标
    ↓ [contextmenu]
菜单从图标位置弹出
    ↓ [scale 0 → 1, 0.15s]
菜单项高亮 (background: rgba...)
    ↓
点击菜单项
    ↓
执行动作
    ↓ [fadeOut 0.1s]
菜单关闭
```

## 3. 状态定义

### 3.1 Dock 状态

| 状态 | 触发条件 | 视觉表现 | 动画 |
|-----|----------|----------|------|
| **Loading** | 加载中 | 骨架屏/加载动画 | Slide up 0.4s |
| **Normal** | 默认 | 固定底部居中 | - |
| **Dragging** | 拖拽中 | 拖拽图标浮起，阴影增强 | Transform 0.1s |
| **ContextMenu** | 右键菜单打开 | 半透明遮罩，菜单浮动 | Fade in 0.15s |
| **Error** | 加载失败 | 错误提示 | - |

### 3.2 DockIcon 状态

| 状态 | 触发条件 | 视觉表现 | 动画 |
|-----|----------|----------|------|
| **Idle** | 默认 | 正常显示，无指示灯 | - |
| **Hover** | 鼠标悬停 | 缩放 1.2x，tooltip 显示 | Scale 0.2s + Fade in 0.15s |
| **Pressed** | 点击中 | 缩小反馈 | Scale 0.95, 0.1s |
| **Dragging** | 拖拽中 | 抓取效果，阴影增强 | Transform 0.1s |
| **Running** | 应用运行中 | 下方绿色指示灯 | Fade in 0.2s |
| **Snapping** | 吸附中 | 移动到新位置 | Transform 0.2s |

## 4. 手势与交互

### 4.1 鼠标交互

| 手势 | 触发条件 | 动作 | 反馈 |
|-----|----------|------|------|
| 单击 | Click 图标 | 打开/切换应用 | Pressed 状态 0.1s |
| 双击 | Double click 图标 | (预留) | - |
| 拖拽 | Mousedown + move | 移动图标 | 抓取阴影 |
| 右键 | Contextmenu 图标 | 打开菜单 | 菜单弹出 |
| 悬停 | Hover 图标/菜单项 | 高亮显示 | 缩放 + Tooltip |

### 4.2 键盘导航

| 快捷键 | 动作 | 说明 |
|-------|------|------|
| Tab | 切换图标焦点 | 顺序切换 Dock 图标 |
| Shift+Tab | 反向切换图标 | 反向切换 |
| Enter | 触发选中项 | 打开应用 |
| Esc | 关闭菜单/弹窗 | - |

- 交互规范 - 保持风格一致
