OriginOS Architecture

AI Native OS — Pi Agent 驱动的三层架构 · 多 Agent 协作运行时 · 记忆核心 · v2.4.0

Web / Presentation Layer

  • • Next.js App Router (页面/组件/API路由)
  • • Zustand 状态管理 + shadcn/ui 组件库
  • • AppWindowManager 窗体管理
  • • SSE 实时事件流推送
  • • Collaboration UI (MultiAgentLauncher + TopologyGraph)

Service / Integration Layer

  • • Pi Agent Core (core/agent.ts) — Agent 生命周期
  • • RoleAgent / ProjectAgent / SupervisorAgent 三类型
  • • 7 层 System Prompt (Identity → Security)
  • • 本体系统 (Domain → Concept → Instance)
  • • Skill 多源加载 (bundled / project / user)
  • • 文件系统 JSON 存储 (无数据库 MVP)

Collaboration Runtime (Epic 9)

  • • 三层进程隔离: Web → Runtime → Agent 子进程
  • • Session 层: Blackboard + FsEventStore + OrphanReconciler
  • • Engine: DagExecutor (Workflow) + SupervisorMode
  • • Protocol: ACL 消息 + ContractNet 招标-投标
  • • Sandbox: npx tsx Agent Worker + stdio JSON Line
  • • Observability: Logging/Metrics/Tracing/Cost/CircuitBreaker
  • • HITL: pause/resume 通过 AgentProcess.resume()

Memory Core + Cognitive System

  • • Core Memory: Semantic/Factual/Procedural Blocks
  • • Archival Memory: ONNX + HNSW 语义向量检索
  • • Recall Memory: JSONL 对话历史 + cursor 增量读取
  • • Dream: LLM 分析 → [ADD/UPDATE/REMOVE] → 精准编辑
  • • CognitiveManager: KnowledgeProvider + PatternProvider
  • • Practice Log: on_turn_end → 周期批量分析
  • • Frozen Snapshot: 启动时加载知识快照到 Layer 2
