# 交互：项目任务看板

**状态：** Planning；2026-09-14

## 主流程

项目 → 任务 → 看板/协同图 → 任务详情 → 允许的操作 → 权威状态反馈。
新建任务 → 选择已发布方案/任务模板 → 绑定业务对象 → 检查输入 → 创建正式Task；缺输入时显示待补项。

已取消默认折叠；暂停/执行失败显示在卡内。卡片点击与图节点点击使用同一Task详情，WorkItem可定位到具体Agent尝试，查看旧尝试时明确标注。

拖拽与键盘菜单调用同一命令。命令等待时显示处理中；拒绝后恢复原位置并显示缺失条件，不能直接修改UI为完成。进行中换人先请求暂停/交接，旧执行者未失效时显示等待。审批页面显示被审对象版本，过期时拒绝继续批准。

关闭窗口后重新打开订阅原run；应用重启后显示“可继续/待核对/等待审批”，不给已取消任务显示继续。确认未知外部结果时展示操作标识和证据，不默认重发。
