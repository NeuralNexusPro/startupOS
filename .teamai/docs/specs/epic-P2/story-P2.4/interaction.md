## UI 设计方向

根据 PRD 3.1 窗体结构：

```
解决方案窗体
├── 左侧：方案列表（P2.5）
├── 中间：方案编辑区（P2.1/P2.2/P2.3）
└── 右侧：沙盒执行区
    ├── 典型场景列表（3-5 个，可点击）
    ├── 推演过程输出（流式，类似 terminal）
    └── 推演报告 + 本体缺口报告（分区展示）
```

### MVP 阶段简化方案

MVP 阶段可简化为：在当前对话 UI 中通过用户输入「验证方案」触发 Skill 的沙盒阶段，推演结果在对话中展示，无需独立面板。

---

## 用户流程

### MVP 流程（利用 Skill 对话）

1. 用户在对话中输入「验证方案」
2. Skill 生成 3-5 个典型场景
3. 用户选择场景
4. Skill 执行推演，流式输出各 Agent 响应
5. 推演完成后展示推演报告
6. 展示本体缺口报告（按严重程度排序）
7. 提示用户选择：返回第一阶段修改本体 / 忽略继续

### 完整实现流程

1. 用户点击右侧沙盒面板
2. 查看场景列表（3-5 个场景，含正常流、异常流、边界情况）
3. 点击场景卡片选择
4. 点击「开始推演」按钮
5. 推演过程流式展示（类似 terminal）
6. 推演完成后切换到报告 Tab
7. 查看推演报告 + 本体缺口报告
8. 点击「返回修改本体」或「继续」
