# 项目内解决方案会话设计
## 背景
P21-T2 修复合法项目内 Skill 被硬编码 skill- 项目规则拒绝，以及非流式发送错误未展示。
## 目标与非目标
确保入口身份一致、真实流式发送与可见失败；不放宽跨项目访问，不更改模型或方案业务。
## 决策
Core 复用 session-restore 公共校验，只在持久化显式 entryType/entryId 与请求精确匹配时接纳项目内 Skill；缺失元数据沿用旧推导与校验，跨项目仍拒绝。比直接删除校验更安全。
Web 传 solution-design/skill 并使用 Hook 的 sendMessageStream；复用既有本地错误消息，不另建状态系统。初始化重复挂载须确保不会无限等待。
## 边界与并行
Core Task 仅 session-restore.ts 及对应测试。Web Task 仅 SolutionDesign.tsx 及组件测试。两项独立并行，父代理集成。Web -> Core 公共 API，Core 不依赖上层；符合 AGENTS.md。
## 风险与迁移
旧元数据不可凭猜测扩大访问；用跨项目、跨入口、缺失身份和旧技能回归约束。无持久化格式迁移，既有 launcher 创建显式身份。回滚提交即可。
## 验证
先红后绿测试合法项目技能与越权拒绝；组件验证自动开场、手动发送、失败可见和初始化重复挂载。编译真实包后验证归属校验。未调用真实模型，人工复核开窗收到开场并能继续发送。
