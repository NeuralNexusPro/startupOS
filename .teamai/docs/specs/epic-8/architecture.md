**版本:** 1.0
**创建:** 2026-05-09
**状态:** 待实施

---

## 🎯 设计目标

在 Epic 7 数据服务层之上，构建完整的 **数据视图层**，提供多维度的本体数据编辑和管理能力。

### 核心需求

1. **概念 Schema 编辑** — 在数据面板中编辑概念的字段定义（添加/修改/删除字段）
2. **表格批量编辑** — TanStack Table 支持多行实例数据的查看和编辑
3. **本体结构编辑** — 创建/删除领域、概念、概念间关系定义
4. **多视图切换** — 同一数据支持表单/文档/表格/图谱四种视图切换

### 与 Epic 7 的关系

- Epic 7 完成了底层服务层（CRUD、索引、版本、API）
- Epic 8 是前端视图层，直接消费 Epic 7 的 API
- 不修改后端，纯前端开发

## Story 分解

| Story | 标题 | 职责 |
|-------|------|------|
| **8.1** | 概念 Schema 编辑 | SchemaEditor 组件，添加/修改/删除概念字段 |
| **8.2** | 表格视图 | DataTableView (TanStack Table)，批量编辑实例 |
| **8.3** | 本体结构编辑 | 创建/删除领域、概念、概念关系定义 |
| **8.4** | 多视图切换窗体 | DataWindowContent 集成四种视图，切换栏 |
| **8.5** | Agent 实例关系工具 | ontologyDataTools 新增 create/query/delete_instance_relation |

## 依赖关系

```
8.1 (Schema 编辑) ──── 8.2 (表格) ──── 8.4 (多视图切换)
                              │              ▲
8.3 (结构编辑) ───────────────┘              │

8.5 (Agent 关系工具) — 独立，依赖 Epic 7 后端 API（已完成）
```

## 验证方法

1. **Story 8.1**：在数据面板侧边面板中编辑概念字段，保存后 API 响应正确
2. **Story 8.2**：切换到表格视图，可批量编辑实例数据
3. **Story 8.3**：创建新领域/概念/关系，图谱视图实时刷新
4. **Story 8.4**：四种视图可切换，切换不丢失数据
