# OriginOS CE v0.1.44 Changelog

发布日期：2026-07-27

## 优化

- Agent、Skill、RoleAgent 和项目 Agent 统一使用自适应批量打字机渲染，兼顾流式反馈与长内容性能。
- IPC 文本流按时间和容量合并，并定向发送到请求窗体，降低无关窗体更新和主进程压力。
- 长 Markdown 流式阶段使用轻量渲染，完成后恢复完整 GFM、表格和代码高亮。
- 自动滚动仅在用户接近底部时跟随，减少长内容输出期间的布局计算。
- Desktop 日志改为按日期分文件并异步批量写入，工具输出使用有界摘要。

## 修复

- 修复 GPT-5.x 等模型返回阶段计划后提前结束，未完成用户任务的问题。
- 修复工具失败或自动恢复耗尽后，技能窗体没有显示明确失败原因的问题。
- 修复 Windows PowerShell 环境信息缺失及不兼容脚本失败后无法继续的问题。
- 修复流式接收内容与已渲染内容共用状态导致的消息截断、丢失或流式效果消失。
- 修复高频文本增量重复扫描完整正文导致主进程事件循环卡顿和窗口无响应。
- 修复开发态日志级别混乱、单文件持续增长以及大型工具输出重复打印的问题。

## 诊断

- 增加主进程 event-loop lag、renderer 无响应和异常退出日志。
- 增加 Agent 等待模型、模型输出、工具执行和完成判定阶段的低频健康日志。
- 诊断日志只记录长度、哈希、阶段和耗时，不记录用户正文或凭据。
