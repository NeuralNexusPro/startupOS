# Story SENSE.14：IM平台能力发现与Agent按需调用

**Epic：** SENSE  
**状态：** Implemented（本地完成，待提交）  
**优先级：** High  
**负责人：** 待分配  
**创建／更新：** 2026-09-17  
**依赖：** SENSE.12插件Host、现有Agent工具授权与IM调用上下文

作为用户，我希望连接企微、飞书、钉钉后，Agent能够发现并使用已授权的平台能力，以便通过对话操作日程、待办等服务，而无需OriginOS逐项开发业务工具。

## 范围与交付

建立一条可复用的“可信目录 → 授权过滤 → 按需发现 → 执行 → 审计”链路。SDK、工具服务或接口描述是能力来源，SDK安装和聊天连接成功均不等于所有办公能力可用。三平台逐一盘点真实来源和权限，不能把未验证平台标成支持。

本Story只有一个独立交付Task：**SENSE14-T1 能力发现与调用闭环**；其有序工作包见[实施](implementation.md)。一个新增平台操作只需可信目录／平台适配数据变化，不要求Core逐项注册业务工具。

## 验收摘要

- [x] AC1：三平台能力来源、SDK版本、发现方式和授权路径有真实证据；缺失来源明确显示不支持。
- [x] AC2：连接后按需发现可调用能力和schema；新目录操作无需Core改动。
- [x] AC3：调用严格绑定当前连接、授权主体及Agent策略，群聊发送者不能冒用授权账号。
- [x] AC4：日程、待办代表性操作形成真实调用及可追溯结果，失败／不确定结果不报成功。
- [x] AC5：权限变更、停用、重启和目录版本变化正确生效，原消息／文件能力无回归。
