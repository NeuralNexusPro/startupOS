## 1. 快捷键交互设计

### 1.1 快捷键优先级

```
Level 1: Dialog/Modal (最高优先级)
  - Esc: 关闭对话框
  - Enter: 确认操作

Level 2: Spotlight
  - Cmd/Ctrl + K: 打开/关闭
  - ↑↓: 导航
  - Enter: 执行

Level 3: Global (最低优先级)
  - Cmd/Ctrl + ,: 设置
  - Cmd/Ctrl + /: 帮助
```

### 1.2 冲突解决策略

- 高优先级覆盖低优先级
- 同级别按注册顺序
- 用户自定义优先级最高
