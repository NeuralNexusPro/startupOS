# Story 9.9: ACL 消息协议

**Epic:** 9 — Multi-Agent 协作运行时
**状态:** 📋 Planning
**优先级:** High
**估计工时:** 1-2 天

---

## Story 概览

> 作为多 Agent 协作的通信基础，我需要标准化的消息协议让 Agent 之间可以请求、告知、委托和订阅，这样协作不依赖硬编码。

**目标：** 实现 ACL 消息协议，支持请求-响应匹配、消息路由、对话流隔离和消息格式验证。
