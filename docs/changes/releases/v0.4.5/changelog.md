# Changelog - v0.4.5

本版本修复浅色窗体的聊天输入框在深色模式下出现浅色背景、浅色文字而难以阅读的问题，并改善 Windows 从旧版覆盖安装与应用内更新失败的问题。

## 2026-10-09 — fix：聊天输入框随窗体保持可读配色

**类型**：fix
**影响模块**：Agent/Skill 会话、项目访谈输入框
**摘要**：浅色窗体的输入栏明确使用浅色背景与深色文字、占位符和按钮；深色窗体继续使用主题色，避免输入文字与背景缺乏对比度。

## 2026-10-09 — fix：Windows 覆盖安装与自动更新

**类型**：fix
**影响模块**：Electron 退出流程、自动更新、NSIS 安装器
**摘要**：Windows 应用内更新会先等待渲染服务与其他后台服务退出，再启动安装器；安装器遇到旧版卸载返回码 2 时，以普通静默卸载重试并保留用户数据，只有旧版卸载成功才继续安装。此修复仍需通过 Windows 安装包从 0.4.4 原位升级验证。
