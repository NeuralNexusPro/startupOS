# Story C.5: 经验模式提取引擎

**状态:** 🔴 Not Started
**优先级:** High
**Epic:** [Epic C](../README.md)

## 目标

实现 `PatternProvider`，自动从实践日志中提取经验模式并评估有效性。

## 设计要点

- 模式提取触发机制：
  - 每次 session_end 时分析最近实践日志
  - 或每 N 次 turn 后批量分析
- 有效性评估指标：
  - 工具调用链长度（越短越好）
  - 用户纠正率（越低越好）
  - 任务完成率
- 模式结构：触发条件 → 工具链 → 关键决策 → 效果指标 → 反模式
- `prefetch(query)` — 根据用户问题匹配相关经验模式
- `sync_turn(user, assistant)` — 对比当前解决路径与已有模式，记录差异

## 验收标准

- [ ] 从实践日志中提取成功路径为模式
- [ ] 模式包含效果指标
- [ ] 低效路径标记为反模式
- [ ] prefetch 能匹配到相关模式
- [ ] 模式文件可被 LLM 直接阅读和执行
