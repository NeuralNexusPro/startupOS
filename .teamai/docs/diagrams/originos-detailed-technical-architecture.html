OriginOS 详细技术架构

子模块级分解 • 数据流 • 依赖注入 • 进程边界 • stdio JSON Line 通信

L1 API Routes + L3 Components

  • • /api/agent/*: sessions lifecycle (create/destroy/messages/summary/statistics)
  • • /api/collaboration/*: sessions (create/execute/abort/human-review/events/blackboard)
  • • /api/skills/*: content loading, executions, message streaming
  • • /api/ontology/*: domain/concept/instance CRUD + generate + validate
  • • /api/projects/*: create/initialize/solutions/sync-ontology/files/export
  • • Components: OS Framework, AppWindow, CUI, SkillDialog, Interview UI, Collaboration Viewer

L2 Integrations — Business Logic Core

  • • Pi Agent Core: OriginOSAgent + AgentManager + SessionStore + usePiAgent Hook
  • • RoleAgent: role-context (7 .md files), state-machine, skill-resolver, 7-layer system-prompt, memory-tracker, dream
  • • ProjectAgent: project-context, project-prompt, Frozen Snapshot mode for Knowledge.md + Patterns.md
  • • Tools: bash-tools, file-tools, skill-tools, ontology-tools, ontology-data-tools
  • • Collab Runtime Service: createSession, executeSession, abortSession, respondToHumanReview, SSE tracking
  • • Skill System: .claude/skills/ (read-only), data/skills/ (runtime), CLAUDE_SKILL_DIR injection

L4 Collaboration Runtime — Independent Module

  • • CollaborationRuntime: DI-based, NO imports from src/lib/ or src/components/
  • • Engine: DagExecutor (Workflow topological sort), SupervisorMode (decompose/assign/verify)
  • • Session: Blackboard (Append-Only + Provenance), FsEventStore (JSONL), OrphanReconciler (PID GC)
  • • Protocol: ACL messages, Contract Net bidding, Subscribe-Notify
  • • Observability: StructuredLogger, MetricsRegistry, Tracer, CostController
  • • Sandbox: AgentSpawner (npx tsx + stdio JSON Line), NodeSandboxExecutor

L5 Worker Processes + L6 Storage

  • • RoleAgent/ProjectAgent/SupervisorAgent: isolated subprocesses via agent-worker.mts
  • • stdio JSON Line protocol: initialize, prompt, ready, waiting, event, resume, tool_result, shutdown
  • • HITL: simplified — direct proc.resume() via globalThis.__globalSpawner, no callback Map
  • • Filesystem: no DB MVP, JSON + JSONL + .md, version tracking (.v{N}.json)
  • • Cognitive: KnowledgeProvider, PatternProvider, PracticeLog, Dream auto-clean
  • • Memory Core: Core Blocks + HNSW Archival + JSONL Recall
