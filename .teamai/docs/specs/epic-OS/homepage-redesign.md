# 首页布局重设计 - macOS/FluentOS 风格

**版本**: v1.0
**日期**: 2026-03-09
**状态**: 设计方案
**设计师**: UX Designer

---

## 1. 问题分析

### 1.1 当前问题

1. **双重底部导航冲突**
   - 底栏和 Dock 同时存在
   - 用户困惑：两个底部导航作用不清晰

2. **左侧导航栏冗余**
   - 占用屏幕空间
   - 与 macOS/FluentOS 风格不符

3. **风格不统一**
   - 混合了多种设计语言
   - 缺乏操作系统的沉浸感

---

## 2. 设计方案

### 2.1 新布局结构

```
┌─────────────────────────────────────────────┐
│ 顶部菜单栏（可选）        🕐 14:30  🔋 ⚙️  │
├─────────────────────────────────────────────┤
│                                             │
│              全屏桌面区域                   │
│                                             │
│     ┌─────┐  ┌─────┐  ┌─────┐             │
│     │项目1│  │项目2│  │项目3│             │
│     └─────┘  └─────┘  └─────┘             │
│                                             │
│     ┌─────┐  ┌─────┐                       │
│     │项目4│  │ + │                         │
│     └─────┘  └─────┘                       │
│                                             │
├─────────────────────────────────────────────┤
│  📁 💻 🎨 🧪 ⚙️  |  🤖 Agent1  🤖 Agent2  │ ← Dock
└─────────────────────────────────────────────┘
```

### 2.2 核心改动

**移除：**
- ❌ 左侧导航栏
- ❌ 其他底栏

**保留/优化：**
- ✅ Dock（唯一底部导航）
- ✅ 项目卡片（网格布局）
- ✅ Spotlight 搜索（Cmd+K）
- ✅ 顶部菜单栏（可选）

---

## 3. 详细设计

### 3.1 桌面区域

**布局：**
- 全屏可用空间
- 项目卡片网格（3-4 列）
- 居中对齐
- 响应式调整

**项目卡片：**
```
┌─────────────────┐
│  [项目图标]     │
│                 │
│  项目名称       │
│  最后访问时间   │
└─────────────────┘
```

**尺寸：**
- 卡片: 200x200px
- 间距: 24px
- 圆角: 12px

### 3.2 Dock 设计

**功能区域：**
```
[固定应用] | [运行中应用] | [系统托盘]
```

**交互：**
- 悬停放大效果
- 右键菜单
- 拖拽排序
- 运行指示器

### 3.3 顶部菜单栏（可选）

**左侧：**
- Logo / 应用名称

**右侧：**
- 时间
- 系统图标（电池、网络、设置）
- 用户头像

---

## 4. 导航方式

### 4.1 主要导航

| 功能 | 方式 |
|-----|------|
| 搜索 | Cmd+K (Spotlight) |
| 应用切换 | Dock 点击 |
| 项目访问 | 桌面卡片点击 |
| 设置 | 顶部菜单栏 |

### 4.2 快捷键

- `Cmd+K`: Spotlight 搜索
- `Cmd+,`: 设置
- `Cmd+Tab`: 应用切换

---

## 5. 响应式设计

### 5.1 桌面 (>1024px)

- 3-4 列网格
- 完整 Dock
- 顶部菜单栏

### 5.2 平板 (768-1024px)

- 2-3 列网格
- 简化 Dock
- 顶部菜单栏

### 5.3 移动 (<768px)

- 1-2 列网格
- 底部导航栏（替代 Dock）
- 汉堡菜单
