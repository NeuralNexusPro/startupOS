OriginOS 技术架构

5 层单向依赖 — Web → Components → Integrations → Collaboration Runtime → Agent Worker → Storage / Cognitive

L1 Web + L3 Components

  • • Next.js App Router (L1): Agent API, Collaboration API, Ontology API
  • • API Routes 是纯委托层，所有业务逻辑在 src/lib/ 和 src/modules/ 中
  • • Components (L3): OS Framework, AppWindowManager, SkillDialog, Interview UI, Collaboration Viewer
  • • Zustand 状态管理 + SSE 实时更新

L2 Integrations

  • • Pi Agent Core: OriginOSAgent, RoleAgent, ProjectAgent, PersistentAgent
  • • 7-Layer System Prompt + State Machine + Dream 自动记忆
  • • Skill System: 多源加载 (bundled/project/user), .claude/skills/ 只读
  • • Collab Runtime Service: Session 管理 + DAG 编排 + HITL via Spawner

L4 Collaboration Runtime

  • • Agent Spawner: npx tsx 子进程 + stdio JSON Line + HMR-safe singleton
  • • Engine: DAG Executor (Workflow) + Supervisor (System) + Conflict Detection
  • • Session: Blackboard (Append-Only + Provenance) + FsEventStore (JSONL)
  • • OrphanReconciler: PID-based GC, Grace Period SSE disconnect

L5 Agent Workers + L6 Storage

  • • RoleAgent / ProjectAgent / SupervisorAgent: 隔离子进程, Frozen Snapshot 模式
  • • HITL: pause/resume via stdin resume command (简化回调机制)
  • • Filesystem Storage: 无数据库 MVP, JSON + JSONL + .md 文件
  • • Cognitive System + Memory Core + Skill Registry: 全局横切系统
