## ⚡ 性能测试指标

### 关键性能指标 (KPI)

| 指标 | 目标值 | 测试场景 |
|------|--------|---------|
| 文件列表加载 | < 500ms | 100 个文件 |
| 文件内容加载 | < 300ms | 100KB Markdown |
| 文件保存响应 | < 200ms | 单次保存 |

| 版本列表加载 | < 300ms | 10 个版本 |
| 文件创建响应 | < 400ms | 创建新文件 |
| 文件删除响应 | < 300ms | 正常删除 |
| 搜索响应时间 | < 200ms | 1000 个文件 |

### 阶段 1: API 测试 (优先级 P0)

**前置条件:** API 端点实现完成

**测试顺序:**
1. POST /api/files (创建)
2. GET /api/files (列表)
3. GET /api/files/:id (详情)
4. PUT /api/files/:id (更新)
5. DELETE /api/files/:id (删除)

**预期时间:** 2-3 天
