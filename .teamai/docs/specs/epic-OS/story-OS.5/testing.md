## 2. 测试用例

### 2.1 视觉效果测试 (P0)

#### TC-VIS-001: AcrylicPanel 模糊效果验证

**前置条件:**
- 开发服务器运行在 localhost:3000
- 页面包含 AcrylicPanel 组件

**测试步骤:**
1. 访问 /desktop 页面
2. 打开 Agent 对话框（使用 AcrylicPanel）
3. 验证背景模糊效果
4. 验证半透明背景
5. 验证边框和阴影

**预期结果:**
- ✅ 背景内容可见但模糊
- ✅ 半透明效果正确 (72%/85%/60% 根据变体)
- ✅ 边框可见 (白色半透明)
- ✅ 阴影效果柔和

#### TC-VIS-002: AcrylicDialog 渲染验证

**前置条件:**
- 开发服务器运行

**测试步骤:**
1. 点击 Dock Agent 图标打开对话框
2. 验证对话框居中显示
3. 验证标题、内容、操作区布局
4. 验证动画效果 (淡入 + 缩放)

**预期结果:**
- ✅ 对话框居中
- ✅ 标题清晰可见
- ✅ 内容区域可滚动
- ✅ 关闭按钮可见
- ✅ 动画流畅 (200ms)

#### TC-VIS-003: 三种变体验证

**测试步骤:**
1. 测试 standard 变体 (72% 透明, 20px 模糊)
2. 测试 subtle 变体 (85% 透明, 12px 模糊)
3. 测试 strong 变体 (60% 透明, 30px 模糊)

**预期结果:**
- ✅ 各变体透明度正确
- ✅ 各变体模糊强度不同
- ✅ 视觉层次清晰

### 2.2 性能测试 (P0)

#### TC-PERF-001: 渲染帧率测试

**测试步骤:**
1. 打开 Chrome DevTools Performance 面板
2. 录制打开/关闭对话框操作
3. 分析帧率数据

**预期结果:**
- ✅ 动画帧率 >= 60fps
- ✅ 无明显卡顿
- ✅ GPU 加速启用

#### TC-PERF-002: 内存占用测试

**测试步骤:**
1. 打开 Chrome DevTools Memory 面板
2. 记录初始内存
3. 打开 10 个 AcrylicDialog
4. 记录内存变化
5. 关闭所有对话框
6. 检查内存回收

**预期结果:**
- ✅ 单个组件内存 < 5MB
- ✅ 关闭后内存正确回收

#### TC-PERF-003: backdrop-filter 性能

**测试步骤:**
1. 滚动页面观察模糊效果
2. 测试多个 AcrylicPanel 同时渲染
3. 监控 GPU 使用率

**预期结果:**
- ✅ 滚动时模糊效果稳定
- ✅ GPU 使用率合理
- ✅ 无性能警告
