# 需求文档 - Story 9.14

**Story:** 招标-投标 + 订阅-通知协议
**Epic:** 9 — Multi-Agent 协作运行时
**最后更新:** 2026-07-20

---

## 用户故事

> 作为协作运行时，我需要实现标准化的交互协议，让 Agent 之间可以招标-投标分配任务和订阅-通知事件，而不依赖硬编码的调用关系。

---

## 功能需求

### 招标-投标协议（Contract Net）

实现任务分配的标准化协议：
- 任务发布者发送招标公告
- 符合条件的 Agent 提交投标
- 发布者评估投标并选择中标者
- 中标 Agent 执行任务并返回结果

### 订阅-通知协议（Subscribe-Notify）

实现事件驱动的订阅机制：
- Agent 可以订阅感兴趣的事件类型
- 事件发生时自动通知所有订阅者
- 支持动态订阅和取消订阅

---

## 验收标准

1. Agent 可以通过招标-投标协议分配和接收任务
2. Agent 可以订阅事件并在事件发生时收到通知
3. 协议实现不依赖硬编码的调用关系
4. 协议消息格式符合 ACL 消息协议规范

---

## 边界条件

- 招标超时未收到投标的处理
- 多个 Agent 同时投标的选择策略
- 订阅者离线时的消息处理
- 事件通知的可靠性保证
