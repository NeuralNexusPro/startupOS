## 1. 交互流程

### 1.1 Agent 启动流程

```
用户点击 Agent 图标
    ↓
Agent 状态: idle → running
    ↓
Dock 显示运行指示器
    ↓
对话窗口打开（Acrylic）
```

### 1.2 对话交互流程

```
用户输入消息
    ↓
消息发送到 Agent
    ↓
Agent 状态: running
    ↓
显示响应（流式）
    ↓
Agent 状态: idle
```

---

## 2. 视觉规范

### 2.1 Agent 图标状态

| 状态 | 视觉效果 | 说明 |
|-----|---------|------|
| idle | 正常图标 | 空闲状态 |
| running | 脉动动画 | 运行中 |
| error | 红色边框 | 错误状态 |

### 2.2 对话窗口

```
┌─────────────────────────────┐
│ [Agent Icon] Agent Name  [x]│ ← 标题栏
├─────────────────────────────┤
│                             │
│  User: Hello                │
│  Agent: Hi! How can I help? │
│                             │
├─────────────────────────────┤
│ [Input field]          [→] │ ← 输入区
└─────────────────────────────┘
```

---

## 3. 动画规范

- 窗口打开: 300ms fade + scale
- 状态切换: 200ms transition
- 脉动动画: 2s infinite
