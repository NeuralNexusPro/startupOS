## 1. 设计概述

### 1.1 设计目标

让 Agent 对象在 OriginOS 的 Desktop 和 Dock 中自然显示和交互：
- 直观的状态表示（idle、running、paused、error）
- 清晰的视觉区分（不同 Agent 类型）
- 流畅的交互反馈（悬停、点击、拖拽）
- 与 App 图标保持一致的交互模式

### 1.2 设计原则

| 原则 | 实施 |
|-----|------|
| **一致性** | Agent 与 App 图标交互保持一致 |
| **状态感知** | Agent 状态实时反映在 UI 上 |
| **类型区分** | 5 种 Agent 类型有明确的视觉区分 |
| **可访问性** | 支持键盘导航和屏幕阅读器 |

### 1.3 设计参考

- **OS.2 Dock**: 图标交互模式（悬停放大、右键菜单）
- **macOS HIG**: 状态指示灯设计
- **Material Design 3**: 状态反馈规范

## 2. 交互流程

### 2.1 Agent 加载流程

```
系统启动
    ↓
pi-agent-core 初始化
    ↓
AgentRegistry.registerAgent() [注册所有 5 种 Agent]
    ↓↓
├─ Agent-PM:       type=pm, icon=📋, status=idle
├─ Agent-Arch:     type=architect, icon=🏗️, status=idle
├─ Agent-Dev:      type=developer, icon=💻, status=idle
├─ Agent-QA:       type=qa, icon=🧪, status=idle
└─ Agent-UX:       type=ux-designer, icon=🎨, status=idle
    ↓
Dock 渲染 Agent 图标
    ↓ [fadeIn 0.3s staggered]
Agent 图标依次显示在 Dock
    ↓
初始状态: 所有 Agent 指示灯为灰色 (idle)
```

---

### 2.2 Agent 启动流程（点击）

```
用户点击 Agent 图标 (click)
    ↓ [50ms]
图标按压缩放 (scale 0.95)
    ↓ [100ms]
图标恢复 (scale 1.0)
    ↓
调用 AgentRegistry.updateAgentStatus(id, 'running')
    ↓
Agent 状态: idle → running
    ↓ [200ms]
指示灯颜色: 灰色 → 绿色
    ↓
打开 Agent 对话窗口
    ↓ [slideUp 0.3s]
对话窗口从 Dock 位置滑出
```

---

### 2.3 Agent 运行中流程

```
对话窗口打开
    ↓
用户与 Agent 对话
    ↓
Agent 执行任务
    ↓
状态保持: running
    ↓
指示灯颜色: 绿色
    ↓
用户点击桌面其他区域
    ↓
对话窗口最小化到 Dock（可选）
    ↓
Agent 状态: running → idle（任务完成）
    ↓
指示灯颜色: 绿色 → 灰色
```

---

### 2.4 Agent 右键菜单流程

```
用户右键点击 Agent 图标
    ↓ [contextmenu]
菜单弹出 [scale 0 → 1, 0.15s]
    ↓
菜单选项显示:
    ├─ 📂 打开对话
    ├─ ⏸ 暂停
    ├─ ▶️ 恢复
    ├─ ⏹ 停止
    └─ 🔄 重启
    ↓
用户点击菜单项
    ↓
执行相应动作
    ↓ [fadeOut 0.1s]
菜单关闭
```

---

### 2.5 Agent 状态变化流程

```
Agent 状态变化 (系统触发)
    ↓
AgentRegistry 状态更新
    ↓ [事件总线]
订阅 UI 组件收到状态变化
    ↓
更新 AgentIcon 组件
    ↓
指示灯颜色变化 [color 0.2s]
    ├─ idle:   灰色 (#9CA3AF)
    ├─ running: 绿色 (#10B981)
    ├─ paused: 黄色 (#F59E0B)
    └─ error:  红色 (#EF4444)
```

## 3. 状态定义

### 3.1 Agent 对象状态

| 状态 | 触发条件 | 视觉表现 | 动画 |
|-----|----------|----------|------|
| **Idle** | 默认、任务完成 | 图标正常，指示灯灰色 | - |
| **Hover** | 鼠标悬停 | 缩放 1.2x，Tooltip 显示 | Scale 0.2s |
| **Pressed** | 点击中 | 缩小 0.95x | Scale 0.1s |
| **Active** | 激活状态 | 边框高亮 | Outline 0.15s |
| **Dragging** | 拖拽中 | 浮起阴影 | Transform 0.1s |

### 3.2 Agent 运行状态指示灯

| 运行状态 | 指示灯颜色 | 出现条件 |
|---------|-----------|---------|
| **Idle** | 灰色 (#9CA3AF) | Agent 未被使用 |
| **Running** | 绿色 (#10B981) | Agent 正在执行任务 |
| **Paused** | 黄色 (#F59E0B) | Agent 任务暂停 |
| **Error** | 红色 (#EF4444) | Agent 出现错误 |

## 4. 视觉规范

### 4.1 Agent 在 Dock 中的显示

**尺寸规范**:

| 元素 | 尺寸 | 说明 |
|-----|------|------|
| Agent 图标 | 32px × 32px | 与 Dock App 图标一致 |
| 指示灯大小 | 4px × 4px | 圆形，位于图标下方居中 |
| 指示灯距离 | 6px | 指示灯与图标间距 |

**颜色规范**:

| 元素 | 颜色 | 说明 |
|-----|------|------|
| 图标背景 | transparent | 透明背景 |
| 指示灯灰色 | #9CA3AF | Idle 状态 |
| 指示灯绿色 | #10B981 | Running 状态 |
| 指示灯黄色 | #F59E0B | Paused 状态 |
| 指示灯红色 | #EF4444 | Error 状态 |

**Agent 类型图标**:

| 类型 | emoji | 说明 |
|-----|-------|------|
| PM | 📋 | 产品经理 |
| Architect | 🏗️ | 系统架构师 |
| Developer | 💻 | 开发工程师 |
| QA | 🧪 | 质量工程师 |
| UX Designer | 🎨 | 交互设计师 |

**Agent 类型颜色** (可选用于区分):

| 类型 | 颜色 | 用途 |
|-----|------|------|
| PM | #3B82F6 (Blue) | 可选图标边框 |
| Architect | #8B5CF6 (Purple) | 可选图标边框 |
| Developer | #10B981 (Green) | 可选图标边框 |
| QA | #F59E0B (Orange) | 可选图标边框 |
| UX Designer | #EC4899 (Pink) | 可选图标边框 |

---

### 4.2 视觉反馈规范

**悬停反馈**:

| 元素 | 效果 | 动画时长 |
|-----|------|---------|
| Agent 图标 | 缩放 1.2x | scale 0.2s |
| Tooltip | 淡入 | fadeIn 0.15s |
| 指示灯 | 放大 1.3x | scale 0.2s |

**点击反馈**:

| 元素 | 效果 | 动画时长 |
|-----|------|---------|
| Agent 图标 | 缩小 0.95x | scale 0.1s |
| 状态动画 | 涟漪扩散 | 0.3s |

**拖拽反馈**:

| 元素 | 效果 | 动画时长 |
|-----|------|---------|
| Agent 图标 | 浮起 + 阴影增强 | Transform 0.1s |
| 目标位置 | 高亮 | Highlight 0.15s |

---

### 4.3 动画规范

**缓动函数** (Fluent Design):

| 动画类型 | 缓动函数 | 持续时间 |
|---------|----------|----------|
| **悬停放大** | cubic-bezier(0.36, 0, 0.66, -0.56) | 0.2s |
| **点击反馈** | cubic-bezier(0.4, 0, 0.2, 1) | 0.1s |
| **状态切换** | cubic-bezier(0.16, 1, 0.3, 1) | 0.2s |
| **菜单弹出** | cubic-bezier(0.16, 1, 0.3, 1) | 0.15s |

## 5. 手势与交互

### 5.1 鼠标交互

| 手势 | 触发条件 | 动作 | 反馈 |
|-----|----------|------|------|
| 单击 | Click Agent | 打开 Agent 对话 | 图标 Pressed 状态 0.1s |
| 双击 | Double click Agent | (预留) | - |
| 拖拽 | Mousedown + move | 移动 Agent 排序 | 悬浮阴影 |
| 右键 | Contextmenu Agent | 打开右键菜单 | 菜单弹出 |
| 悬停 | Hover Agent | 高亮 + Tooltip | 缩放 + Tooltip |

### 5.2 键盘导航

| 快捷键 | 动作 | 说明 |
|-------|------|------|
| Tab | 切换焦点 | 顺序切换 Dock 元素 |
| Shift+Tab | 反向切换 | 反向切换 |
| Enter | 触发选中项 | 相当于单击 Agent |
| Esc | 关闭菜单/弹窗 | 关闭右键菜单 |

## 6. 可访问性

### 6.1 ARIA 属性

```html
<div
  class="dock-agent"
  role="button"
  tabindex="0"
  aria-label="产品经理 PM Agent"
  aria-describedby="agent-status-pm"
  onkeydown="handleKeydown(event)"
  onclick="handleClick()"
>
  <div class="agent-icon">📋</div>
  <div class="agent-indicator" aria-hidden="true"></div>
</div>

<div id="agent-status-pm" class="sr-only">
  状态: {{agentStatus}}
</div>
```

## 8. 响应式规范

### 8.1 断点定义

| 断点 | Dock 布局 | Agent 显示规则 |
|------|----------|----------------|
| **Desktop Large** | ≥ 1920px | 全部 5 个 Agent + Apps |
| **Desktop Medium** | 1366-1919px | 5 个 Agent + 主要 Apps |
| **Tablet** | ≤ 1365px | 5 个 Agent (间距缩减) |

### 8.2 响应式调整

| 屏幕尺寸 | 图标大小 | 间距 |
|---------|---------|------|
| Desktop | 32px | 6px |
| Tablet | 28px | 4px |
