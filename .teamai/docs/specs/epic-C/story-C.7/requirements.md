# 需求文档 - Story C.7

**Story:** 角色知识体系插拔
**Epic:** Epic C
**最后更新:** 2026-07-20

## 目标

为 RoleAgent 提供可插拔的知识体系挂载能力。

## 设计要点

- RoleAgent 的知识库通过 `.skills/` 目录或配置目录挂载
- 知识库与项目知识库合并（角色知识 + 项目知识 → 统一检索）
- 角色知识体系定义通过 schema.md 约定
- 知识作用域：角色私有知识 vs 项目共享知识

## 验收标准

- [ ] RoleAgent 启动时加载角色知识库
- [ ] 角色知识与项目知识合并
- [ ] 插拔机制通过配置目录或软链接实现
- [ ] 知识作用域隔离正确
