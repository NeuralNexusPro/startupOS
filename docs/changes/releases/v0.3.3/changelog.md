# OriginOS CE v0.3.3

发布日期：2026-09-25

## 感知与 IM 路由

- 为同一发送者、连接和会话增加有界 sticky 路由，连续对话沿用已选角色；用户要求换助手时可重新选择，明确点名角色时直接切换。
- 将“请用户选择角色或能力”作为独立智能决策候选，与“仅通知用户”分离；旧规则在运行时自动兼容。
- 修复决策接续消息显示未命中规则、部分选择没有回应、Jev 失败缺少 IM 兜底以及决策诊断信息不足的问题。
- 感知中心使用中文资产名称展示候选、概率和执行结果，并保留人工选择后的实际路由状态。

## 企业微信办公能力

- 企业微信日程等办公能力按当前感知源连接绑定授权，避免多个机器人之间串用身份。
- 改进办公能力发现、输入校验、调用结果解析和授权状态处理，减少能力已执行却被标记为结果不确定的情况。
- 感知源保存流程支持办公授权接续，插件日志保持独立、脱敏并关联事件诊断信息。

## Agent 与任务协作

- 修复工具调用先失败后成功仍被完成守卫误判的问题，并补强 IM 能力调用与历史会话标题处理。
- 多 Agent WorkItem 增加契约绑定恢复和受控证据写入；项目任务看板第一阶段接入权威任务投影、状态分栏、详情和受控操作。
- 补强项目本体跨包读写、冲突恢复及 Desktop IPC 适配。

## 验证

- Core 感知与 Jev、Desktop Plugin Host、Web 感知中心专项测试通过。
- Core、Desktop、Web TypeScript 检查通过；架构扫描 919 个生产文件，0 条诊断；Web lint 0 error。
- Windows、macOS arm64 和 macOS x64 安装包由 Desktop Release 工作流构建、校验并发布。
