# SENSE.11 交互

## 用户流程

1. 感知中心选择“企业微信”。
2. 填写连接 ID、智能机器人 Bot ID、环境变量前缀。
3. 页面提示需要设置的 `${PREFIX}_SECRET`，并说明无需公网回调地址。
4. 保存后连接保持停用；Secret 准备完成并重启 Desktop 后在列表启用。
5. 在企业微信中向机器人单聊或在群内 @机器人完成验证。

## 状态与提示

- 默认：展示具体示例，不展示空泛 Endpoint。
- 保存中：按钮禁用并显示“正在保存…”。
- 校验失败：字段附近/表单底部给出可执行修正提示。
- 浏览器模式：允许配置环境引用；明确密钥由运行服务读取。

## 可访问性与响应式

所有输入具有关联标签、错误使用 `role=alert`、键盘可完成保存和复制；窄屏单列，宽屏双列。沿用感知中心蓝灰色系统面板，不引入新字体或装饰性动画。
