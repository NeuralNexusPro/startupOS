## 1. 设计概述

### 1.1 设计目标

让 Desktop 空间的交互体验接近原生操作系统：
- 流畅的拖拽交互
- 直观的右键菜单
- 自然的响应式切换
- 原生级的手势反馈

### 1.2 设计原则

| 原则 | 实施 |
|-----|------|
| **原生 OS 感** | 参考 macOS Desktop 交互模式 |
| **Fluent 风格** | 使用 Fluent 动画缓动 |
| **流畅优先** | 60fps 稳定动画 |
| **简洁直观** | 遵循用户已有习惯 |

### 1.3 设计参考

- **macOS Desktop**: 图标拖拽、网格吸附
- **Fluent Design**: 微交互、缓动函数
- **Windows 11**: Snapping、圆角交互

## 2. 交互流程

### 2.1 Onboarding 流程

```
用户打开 OriginOS
    ↓
Desktop 空间加载
    ↓ [2s]
状态栏淡入 (fadeIn 0.3s)
    ↓
图标依次淡入 (staggered 0.1s)
    ↓
完成进入，等待用户交互
```

### 2.2 图标拖拽流程

```
用户按住图标
    ↓ [mousedown]
图标浮起 (transform: translateY(-8px) scale(1.05))
    ↓
阴影增强 (box-shadow: 0 20px 40px rgba(0,0,0,0.3))
    ↓ [dragging]
移动时跟随鼠标
    ↓
经过网格位置时，其他图标移开（动画 0.2s）
    ↓ [mouseup]
如果在新位置：
    ↓
吸附到网格位 (snap 0.2s)
    ↓
回落到正常状态 (transform: none, box-shadow: normal)
```

### 2.3 右键菜单流程

```
用户右键点击桌面空白处
    ↓ [contextmenu]
菜单从鼠标位置弹出
    ↓ [scaleY 0 → 1, 0.15s]
背景遮罩（可选）
    ↓
菜单项悬停高亮 (background: rgba(0,0,0,0.06))
    ↓
点击菜单项
    ↓
执行动作
    ↓ [fadeOut 0.1s]
菜单关闭
```

### 2.4 响应式切换流程

```
窗口大小改变 (resize)
    ↓ [debounce 100ms]
检测新尺寸
    ↓ [0.2s transition]
重新计算图标网格
    ↓
图标重新排列（如果需要）
    ↓
完成响应式适配
```

## 3. 状态定义

### 3.1 Desktop 状态

| 状态 | 触发条件 | 视觉表现 | 动画 |
|-----|----------|----------|------|
| **Loading** | 加载中 | 骨架屏/加载动画 | Fade in 0.3s |
| **Normal** | 默认 | 全屏显示，图标排列 | - |
| **Dragging** | 拖拽中 | 拖拽图标浮起，其他图标移开 | Transform 0.1s |
| **ContextMenu** | 右键菜单打开 | 半透明遮罩，菜单浮动 | Fade in 0.15s |
| **Error** | 加载失败 | 错误提示，重试按钮 | - |

### 3.2 图标状态

| 状态 | 触发条件 | 视觉表现 | 动画 |
|-----|----------|----------|------|
| **Idle** | 默认 | 正常显示 | - |
| **Hover** | 鼠标悬停 | 轻微放大，背景高亮 | Scale 1.05, 0.2s |
| **Dragging** | 拖拽中 | 浮起，阴影增强 | Transform 0.1s |
| **Active** | 点击中 | 缩小反馈 | Scale 0.95, 0.1s |
| **Snapping** | 吸附中 | 移动到网格位 | Transform 0.2s |

## 4. 手势与交互

### 4.1 鼠标交互

| 手势 | 触发条件 | 动作 | 反馈 |
|-----|----------|------|------|
| 单击 | Click 图标 | 打开/触发 | Active 状态 0.1s |
| 双击 | Double click 图标 | (预留) | - |
| 拖拽 | Mousedown + move | 移动图标 | 悬浮阴影 |
| 右键 | Contextmenu | 打开菜单 | 菜单弹出 |
| 悬停 | Hover 图标/菜单项 | 高亮显示 | 背景/缩放 |

### 4.2 键盘导航

| 快捷键 | 动作 | 说明 |
|-------|------|------|
| Cmd/Ctrl + K | 打开 Spotlight | (OS.4) |
| Esc | 关闭菜单/弹窗 | - |
| Tab | 切换焦点 | 顺序切换图标 |
| Enter | 触发选中项 | 相当于单击 |

### 4.3 触摸交互（平板）

| 手势 | 动作 | 说明 |
|-----|------|------|
| 长按 | 右键菜单 | 右键菜单替代 |
| 拖拽 | 移动图标 | 与鼠标手势相同 |

## 5. 动画规范

### 5.1 Fluent 动画缓动

| 动画类型 | 缓动函数 | 持续时间 | 用途 |
|---------|----------|----------|------|
| **Fluent Default** | cubic-bezier(0.36, 0, 0.66, -0.56) | 0.32s | 默认过渡 |
| **Quick** | cubic-bezier(0.4, 0, 0.2, 1) | 0.15s | 快速反馈 |
| **Smooth** | cubic-bezier(0.16, 1, 0.3, 1) | 0.5s | 大型动画 |
| **Snap** | cubic-bezier(0.34, 1.56, 0.64, 1) | 0.2s | 网格吸附 |

### 5.2 具体动画

```css
/* 图标悬停 */
.desktop-icon {
  transition: transform 0.2s ease-out, box-shadow 0.2s ease-out;
}

.desktop-icon:hover {
  transform: translateY(-2px) scale(1.05);
  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.3);
}

/* 右键菜单弹出 */
.context-menu {
  transition: opacity 0.15s ease-out, transform 0.15s cubic-bezier(0.16, 1, 0.3, 1);
  opacity: 0;
  transform: scale(0.95);
  transform-origin: var(--menu-origin);
}

.context-menu.open {
  opacity: 1;
  transform: scale(1);
}

/* 响应式切换 */
.desktop-grid {
  transition: grid-template-columns 0.2s fluent, gap 0.2s fluent;
}
```

| 类型 | 色值 | 用途 |

| 元素 | 尺寸 | 响应式 |

## 8. 响应式规范

### 8.1 断点定义

| 断点 | 尺寸 | 布局 | 图标列数 |
|-----|------|------|----------|
| **Desktop Large** | ≥ 1920px | 4 列 | 4 |
| **Desktop Medium** | 1366-1919px | 3 列 | 3 |
| **Tablet** | ≤ 1365px | 2 列 | 2 |

### 8.2 响应式规则

```css
/* Desktop Large (default) */
@media (min-width: 1920px) {
  .desktop-grid {
    grid-template-columns: repeat(4, 1fr);
    gap: 24px;
  }
}

/* Desktop Medium */
@media (min-width: 1366px) and (max-width: 1919px) {
  .desktop-grid {
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
  }
}

/* Tablet */
@media (max-width: 1365px) {
  .desktop-grid {
    grid-template-columns: repeat(2, 1fr);
    gap: 16px;
  }

  .desktop-icon {
    width: 56px;
    height: 56px;
  }
}
```

## 9. 可访问性

### 9.1 键盘导航

- Tab 键顺序：Desktop 图标 → Dock → Spotlight (OS.4)
- Enter 键：触发当前焦点元素
- Escape 键：关闭菜单/弹窗

### 9.2 屏幕阅读器

```html
<div class="desktop" role="grid" aria-label="桌面图标">
  <div
    class="desktop-icon"
    role="gridcell"
    tabindex="0"
    aria-label="设置"
    onkeydown="handleKeydown(event)"
    onclick="handleClick()"
  >
    <div class="icon-container">⚙️</div>
    <span class="icon-label">设置</span>
  </div>
</div>
```

### 9.3 ARIA 状态

| 状态 | 属性 | 值 |
|-----|------|-----|
| 拖拽中 | aria-dropeffect | move |
| 焦点 | aria-selected | true/false |
| 菜单打开 | aria-expanded | true/false |
