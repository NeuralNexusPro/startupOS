# SENSE.13 需求

## 来源与详细需求

来源为用户对 SENSE.9 首页入口的反馈。SENSE.9 的管理窗体保持不变，本 Story 只重构发现入口与连接健康摘要，并以新决策替代其“不得注册进 homeApps.ts”约束。

1. 首页应用启动器增加 action 类型“感知与连接”，排序在“工作区”之后，可固定到 Dock。
2. 删除独立整行感知横幅；入口统一调用 `openSenseCenter()`，不得复制窗体业务逻辑。
3. 顶部系统栏增加感知状态按钮；点击显示连接总数、正常/异常数量、最近事件时间和管理入口。
4. 状态由既有 management 数据派生：无连接为未配置；全部启用连接健康为正常；部分异常为警告；全部启用连接异常为中断。
5. 加载失败显示未知状态和管理入口，不输出 Secret、secretRef 或原始异常。
6. 首页应用启动器的创建入口组增加“创建技能”，复用 `skill-creator-app` 及 Dock 中已有的 `skill-creator` 应用身份。

## 验收标准

- Given 用户打开首页，When 查看应用启动器，Then 能看到“感知与连接”且不再看到独占横幅。
- Given 用户点击卡片或 Dock 图标，When 入口触发，Then 复用同一个感知中心窗体并聚焦已有实例。
- Given 存在正常或异常连接，When 打开顶部状态面板，Then 显示语义状态、分连接摘要和最近事件，并可进入完整管理窗体。
- Given 数据加载失败或没有连接，When 查看状态入口，Then 分别显示“状态未知”或“尚未连接”，且仍可进入管理。
- Given 用户查看创建入口，When 点击“创建技能”，Then 通过通用 Skill 启动链路打开 `skill-creator-app`。

## 边界、异常与非功能需求

覆盖连接数为 0、全部停用、混合健康、全部异常、无事件、API 失败和重复点击。状态按钮响应 <500ms；不增加高频轮询；WCAG AA、可见焦点、44px 触摸目标。依赖 SENSE.8、SENSE.9、SENSE.12；仅使用既有 React、Tailwind、shadcn、Zustand 和 API，无数据库或新后端。
