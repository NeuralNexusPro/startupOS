# Story OS.7: Agent 托管服务 - 产品需求文档 (PRD)

**版本**: v1.0
**日期**: 2026-03-09
**状态**: 草稿
**批准状态**: 待批准

---

## 1. 产品概述

### 1.1 产品目标

创建 Agent 托管服务，让 AI Agent 在 OriginOS 中可视化运行和交互。

### 1.2 核心价值

- **可视化**: Agent 在桌面/Dock 中显示
- **交互性**: 点击打开对话窗口
- **实时性**: 状态同步更新
- **多任务**: 支持多 Agent 并发

---

## 2. 功能需求

### 2.1 核心功能

**F1: Agent 渲染**
- 在 Desktop 显示 Agent 图标
- 在 Dock 显示运行中的 Agent
- 显示 Agent 状态（运行/空闲/错误）

**F2: 对话窗口**
- 点击 Agent 打开 Acrylic 对话窗口
- 支持消息输入和显示
- 实时显示 Agent 响应

**F3: 状态管理**
- Agent 状态实时同步
- 支持启动/停止 Agent
- 错误状态提示

**F4: 多 Agent 支持**
- 同时运行多个 Agent
- 独立的对话窗口
- 资源隔离

---

## 3. 技术规范

### 3.1 Agent 状态

```typescript
type AgentStatus = 'idle' | 'running' | 'error' | 'stopped';
```

### 3.2 对话窗口规格

- 尺寸: 600x800px
- 材质: Acrylic
- 位置: 居中或跟随 Agent 图标

---
