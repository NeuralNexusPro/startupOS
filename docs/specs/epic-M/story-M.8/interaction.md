# 交互设计文档 - Story M.8

**Story:** 记忆链路收敛 — 围栏修复 + 新旧合并 + DataFile 对齐
**版本:** 1.0
**最后更新:** 2026-09-09

## 适用性

本 Story 为 core 运行时与本地存储治理，不新增用户界面，因此视觉、响应式和无障碍交互不适用。

## 系统行为

1. Agent 启动时由统一 `MemoryCore` 读取当前格式或兼容旧格式。
2. 旧格式迁移必须保留备份；迁移失败时保留原文件并返回可诊断错误。
3. 会话结束、窗口关闭等入口统一调用 core consolidation，不在 Web/Electron 边界复制逻辑。
4. 对用户可见的会话行为保持兼容，不新增确认步骤或阻塞消息响应。

## 错误与恢复

- 数据损坏：隔离损坏文件，并从有效版本恢复；无法恢复时不得覆盖原数据。
- 迁移失败：记录错误并保留 legacy 文件，下一次启动允许重试。
- embedding 不可用：回退关键词检索，不中断 Agent 会话。
