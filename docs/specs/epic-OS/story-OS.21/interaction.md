# OS.21 交互设计

## 适用性

本 Story 主要是系统运行时重构，不新增普通用户操作界面。现有 OS.16 定时任务界面保持不变；系统任务仅在诊断场景可见，因此不设计独立应用或表单。

## 用户流程

```text
用户启用 Email connector
  → 感知服务注册隐藏系统任务
  → Scheduler 到期调用邮箱轮询 owner
  → 感知服务拉取增量邮件并路由事件
  → 健康状态和安全运行摘要更新

用户停用 Email connector
  → 感知服务注销系统任务
  → 后续不再轮询
```

## 可见状态

- 感知中心继续显示连接器的健康、最近成功时间和安全错误码。
- 定时任务中心默认只显示 `ownerKind=user` 的任务，不出现邮箱内部任务。
- 若未来增加“系统诊断”过滤器，必须明确标注“系统任务/只读”，展示 owner、下次运行、最近状态和退避时间，不展示邮件正文或凭据。

## 错误反馈

- 注册失败：感知连接器状态显示 `degraded` 和稳定安全错误码。
- 连续执行失败：展示下次重试时间，不暴露底层异常或认证信息。
- 配置变更失败：保留原调度项或安全停用，不同时运行新旧配置。

## 响应式与可访问性

本 Story 不新增 UI。任何后续诊断视图必须支持键盘导航、状态文本（不能只靠颜色）以及 400×300 最小窗体。
