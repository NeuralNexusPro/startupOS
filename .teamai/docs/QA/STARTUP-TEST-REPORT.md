### 4. 已知问题与解决方案

问题 1: `Module not found: Can't resolve '@mariozechner/agent'`
- **原因:** 缺少外部依赖包
- **解决:** 临时禁用 pi-agent 集成，将相关 hooks 改为 mock 实现
- **后续:** 需要安装或提供 `@mariozechner/agent` 包，或实现自定义 Agent 包装器

问题 2: 客户端代码导入 Node.js `fs` 模块
- **原因:** Next.js 客户端代码无法使用 Node.js 模块（`fs/promises`）
- **解决:** 将使用 `fs` 的服务端代码与客户端代码分离，使用 mock 数据暂代
- **后续:** 需要通过 API 路由实现服务端功能
