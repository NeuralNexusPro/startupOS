# Story 9.12: UI — 协作查看器

**Epic:** 9 — Multi-Agent 协作运行时
**状态:** 📋 Planning
**优先级:** High
**估计工时:** 3-4 天

---

## Story 概览

> 作为用户，我希望在界面上实时看到多 Agent 协作的执行过程，包括事件时间线、Agent 活动状态和黑板数据，这样我能了解协作进度并及时干预。

**目标：** 实现协作过程查看器 UI，支持事件时间线、Agent 活动卡片、黑板状态视图和 SSE 实时更新。
