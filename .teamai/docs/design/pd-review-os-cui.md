## 3. 核心用户流程验证

### 3.1 主流程验证 ✅

```
用户点击 Dock 图标
        ↓
AppWindow 打开 (useAppWindowManager)
        ↓
AgentDialogContent 初始化 (usePiAgent)
        ↓
显示 Agent 信息 + 在线状态
        ↓
用户输入消息 → Enter 发送
        ↓
ChatInput 清空 + 禁用
        ↓
显示 "思考中..." 动画
        ↓
Agent 回复 → 消息气泡出现
        ↓
输入框恢复 + 自动滚动到底部
```

**流程完整性**: ⭐⭐⭐⭐⭐

### 3.2 异常流程验证 ✅

| 异常场景 | 处理方式 | 用户体验 |
|---------|---------|---------|
| Agent 初始化失败 | 状态显示错误，输入禁用 | ⭐⭐⭐⭐ |
| 消息发送失败 | 错误消息条 + 重试按钮 | ⭐⭐⭐⭐⭐ |
| Agent 处理超时 | 思考状态持续 | ⭐⭐⭐ |
| 网络断开 | 状态变为离线 | ⭐⭐⭐⭐ |

**改进建议**:
- 增加 Agent 处理超时的自动重试机制
- 考虑添加网络状态提示

### 3.3 键盘交互 ✅

## 8. 发现的问题与建议

### 8.1 ThinkingIndicator 组件缺失 ⚠️

**问题**: 设计文档描述了思考指示器，但组件列表中需新建。

**建议**: 在文件结构中明确标记需新建的组件。

### 8.2 多 Agent 并发显示 ⚠️

**问题**: 架构支持多 Agent，但 UI 未说明如何区分。

**建议**: 增加窗口标题或图标区分：

```tsx
// 窗口标题示例
<WindowTitle>
  <AgentIcon icon={agent.icon} />
  {agent.displayName}
</WindowTitle>
```

### 8.3 消息持久化 ⚠️

**问题**: 设计未提及消息历史持久化。

**建议**: 利用现有 `pi-agent store` 的消息历史，或增加本地持久化。

### 8.4 Markdown 渲染预留 ✅

**评估**: 未来扩展设计中已预留 Markdown 支持，符合渐进式演进策略。

## 9. 用户流程文档

### 9.1 主要用户故事

**故事 1: 启动 Agent 对话**

```
作为用户
我想要点击 Dock 图标打开 Agent 对话
以便与 AI 助手进行交互

验收标准:
- 点击 Dock 图标后 200ms 内显示窗口
- 窗口标题显示 Agent 名称
- 输入框自动聚焦
- 状态指示器显示 "在线" 或 "思考中..."
```

**故事 2: 发送消息**

```
作为用户
我想要输入消息并发送给 Agent
以便获得 AI 的帮助

验收标准:
- 输入框支持多行输入 (Shift+Enter)
- Enter 键发送消息
- 发送后输入框清空
- 显示 "思考中..." 动画
- 收到回复后动画消失
```

**故事 3: 查看对话历史**

```
作为用户
我想要滚动查看之前的对话
以便回顾 Agent 的建议

验收标准:
- 消息列表可滚动
- 新消息自动滚动到底部
- 历史消息保持显示
```

### 9.2 异常用户故事

**故事 4: 处理发送失败**

```
作为用户
我想要在消息发送失败时看到错误提示
以便知道发生了什么并可以重试

验收标准:
- 错误时显示红色提示条
- 提示条包含错误信息
- 提供 "重试" 按钮
- 重试按钮重新发送最后一条消息
```
