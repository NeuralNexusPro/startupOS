# OriginOS CE v0.3.0

发布日期：2026-09-21

## 感知与 IM 路由

- 新增 Jev 感知决策：可从设置安全配置服务地址与凭据，并基于已授权的项目、角色和技能描述进行路由。
- 感知中心支持查看决策过程、概率、人工选择与失败重试；规则可写入自然语言认知规则，作为 Jev 的判断指引。
- 企业微信、飞书、钉钉的入站消息不再被静默忽略；候选不明确时在原会话询问用户，决策或执行失败时回复兜底消息。
- 修复 IM 流式回复过于频繁的问题，并保留渠道、会话与发送者元数据到共享记忆。

## Agent 与运行时

- 重构 Agent 上下文装配：稳定提示前缀、按需加载认知目录、按轮预取，并提供会话 Token 与缓存使用统计。
- 统一系统调度运行时，改进定时任务、通知投递和恢复的一致性。

## 项目本体

- 引入 canonical ontology 的类型、存储、旧数据迁移、校验、事实与 Action OSDK，以及执行上下文投影协议。
- Agent 与 Skill 的本体契约可被校验，项目语义上下文为后续可恢复的任务协作提供基础。

## 验证

- Core、Web、Desktop 和感知插件专项测试、TypeScript 编译及架构边界检查通过。
- Desktop Release 工作流将构建 Windows、macOS arm64 和 macOS x64 安装包，并发布更新元数据与 GitHub Release。
