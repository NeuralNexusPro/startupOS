### 概述

作为开发者，我可以注册各种工具（Tool）到核心调度层，以便调度器可以调用这些能力来完成用户指令。

本 Story 实现了统一的工具注册接口、5 个内置工具（文件操作 + 本体操作），以及完整的工具执行生命周期管理（进度更新、取消支持、路径安全校验）。
