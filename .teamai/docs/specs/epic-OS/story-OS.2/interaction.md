## 1. 设计概述

### 1.1 设计目标

让 Dock 的交互体验接近 macOS Dock + Fluent 风格：
- 流畅的悬停动画
- 直观的拖拽排序
- 原生级的菜单体验

### 1.2 设计原则

| 原则 | 实施 |
|-----|------|
| **macOS 启发** | 参考 macOS Dock 布局和交互模式 |
| **Fluent 风格** | 使用 Fluent 动画缓动 |
| **流畅优先** | 60fps 稳定动画 |

### 1.3 设计参考

- **macOS Dock**: 图标排列、运行指示灯、悬停放大
- **Fluent Design**: Acrylic 材质、微交互、缓动函数

## 2. 交互流程

### 2.1 Dock 加载流程

```
Desktop 加载完成
    ↓
Dock 从底部滑入
    ↓ [slideUp 0.3s]
图标依次淡入 (staggered 0.05s)
    ↓
完成加载，等待用户交互
```

### 2.2 应用图标悬停流程

```
鼠标悬停在图标上
    ↓ [0ms]
图标放大 (scale 1.2x)
    ↓ [scale 0.2s Fluent]
显示应用名称 tooltip
    ↓
移开鼠标
    ↓
图标回落到正常状态 (scale 1.0)
    ↓ [scale 0.2s Fluent]
tooltip 淡出
    ↓
完成交互
```

### 2.3 应用点击流程

```
用户点击应用图标
    ↓ [click]
图标产生 Active 状态反馈
    ↓ [scale 0.95, 0.1s]
如果应用未运行：
    ↓
启动应用
    ↓
指示灯出现（绿色）
如果应用已运行：
    ↓
切换到应用窗口
```

### 2.4 拖拽排序流程

```
用户按住图标
    ↓ [mousedown]
图标浮起 (transform: translateY(-8px) scale(1.1))
    ↓
阴影增强 (box-shadow: 0 12px 32px rgba(0,0,0,0.4))
    ↓ [dragging]
移动时跟随鼠标
    ↓
经过其他图标时，其他图标移开（动画 0.15s）
    ↓ [mouseup]
如果在新位置：
    ↓
吸附到新位置 (snap 0.15s)
    ↓
图标重新排列，动画完成
```

### 2.5 右键菜单流程

```
用户右键点击应用图标
    ↓ [contextmenu]
菜单从图标位置弹出
    ↓ [opacity 0 → 1, scaleY 0 → 1, 0.15s]
背景遮罩（可选）
    ↓
菜单项悬停高亮 (background: rgba(0,0,0,0.06))
    ↓
点击菜单项
    ↓
执行动作
    ↓ [fadeOut 0.1s]
菜单关闭
```

## 3. 状态定义

### 3.1 Dock 状态

| 状态 | 触发条件 | 视觉表现 | 动画 |
|-----|----------|----------|------|
| **Loading** | 加载中 | 从底部滑入 | SlideUp 0.3s |
| **Normal** | 默认 | 固定底部居中 | - |
| **Hover** | 悬停图标 | 目标图标 1.2x 放大 | Scale 0.2s |
| **Dragging** | 拖拽中 | 拖拽图标浮起 | Transform 0.1s |
| **ContextMenu** | 右键菜单打开 | 半透明遮罩，菜单浮动 | FadeIn 0.15s |

### 3.2 图标状态

| 状态 | 触发条件 | 视觉表现 | 动画 |
|-----|----------|----------|------|
| **Idle** | 默认 | 正常显示 | - |
| **Hover** | 鼠标悬停 | 放大 1.2x，tooltip 出现 | Scale 0.2s |
| **Active** | 点击中 | 缩小 0.95x | Scale 0.1s |
| **Dragging** | 拖拽中 | 浮起，阴影增强 | Transform 0.1s |
| **Running** | 应用运行中 | 绿色指示灯 | FadeIn 0.15s |

## 4. 手势与交互

### 4.1 鼠标交互

| 手势 | 触发条件 | 动作 | 反馈 |
|-----|----------|------|------|
| 单击 | Click 图标 | 打开/切换应用 | Active 状态 0.1s |
| 拖拽 | Mousedown + move | 移动图标 | 悬浮阴影 |
| 右键 | Contextmenu | 打开菜单 | 菜单弹出 |
| 悬停 | Hover 图标/菜单项 | 高亮显示 | 背景/缩放 |

### 4.2 键盘导航

| 快捷键 | 动作 | 说明 |
|-------|------|------|
| Tab | 切换焦点 | 顺序切换 Dock 图标 |
| Enter | 触发选中项 | 相当于单击 |
| Esc | 关闭菜单 | 关闭右键菜单 |

## 5. 动画规范

### 5.1 Fluent 动画缓动

| 动画类型 | 缓动函数 | 持续时间 | 用途 |
|---------|----------|----------|------|
| **Fluent Default** | cubic-bezier(0.36, 0, 0.66, -0.56) | 0.32s | 默认过渡 |
| **Quick** | cubic-bezier(0.4, 0, 0.2, 1) | 0.15s | 快速反馈 |
| **Smooth** | cubic-bezier(0.16, 1, 0.3, 1) | 0.5s | 大型动画 |

### 5.2 具体动画

```css
/* 图标悬停放大 */
.dock-icon {
  transition: transform 0.2s ease-out;
}

.dock-icon:hover {
  transform: scale(1.2);
}

/* 右键菜单弹出 */
.dock-menu {
  transition: opacity 0.15s ease-out, transform 0.15s cubic-bezier(0.16, 1, 0.3, 1);
  opacity: 0;
  transform: scale(0.95) translateY(8px);
  transform-origin: bottom center;
}

.dock-menu.open {
  opacity: 1;
  transform: scale(1) translateY(0);
}

/* 拖拽排序图标移动 */
.dock-icon.dragging {
  transition: transform 0.15s ease-out;
}

/* Dock 整体滑入 */
.dock {
  animation: slideUp 0.3s cubic-bezier(0.16, 1, 0.3, 1);
}

@keyframes slideUp {
  from {
    transform: translateY(100%);
    opacity: 0;
  }
  to {
    transform: translateY(0);
    opacity: 1;
  }
}
```

## 6. 视觉规范

### 6.1 颜色方案

| 类型 | 色值 | 用途 |
|-----|------|------|
| **Dock 背景** | rgba(255, 255, 255, 0.85) + backdrop-blur(20px) | Glassmorphism 背景 |
| **Dock 边框** | rgba(255, 255, 255, 0.5) | 顶部边框 |
| **图标悬停** | rgba(255, 255, 255, 0.1) | 图标悬停背景 |
| **菜单背景** | rgba(255, 255, 255, 0.95) + backdrop-blur(20px) | 菜单背景 |
| **运行指示灯** | #10B981 | 绿色 |

### 6.2 尺寸规范

| 元素 | 尺寸 | 响应式 |
|-----|------|--------|
| **Dock 容器** | 48px (高度) × 自动 (宽度) | 固定高度 |
| **图标大小** | 32px | 固定 |
| **图标间距** | 6px | 固定 |
| **指标灯大小** | 4px × 4px | 固定 |
| **菜单项高度** | 36px | 固定 |
| **菜单圆角** | 8px | 固定 |

### 6.3 阴影规范

| 级别 | 阴影值 | 用途 |
|-----|--------|------|
| **Level 1** | 0 2px 8px rgba(0,0,0,0.12) | 默认 Dock |
| **Level 2** | 0 4px 16px rgba(0,0,0,0.16) | 菜单 |
| **Level 3** | 0 12px 32px rgba(0,0,0,0.4) | 拖拽图标 |

## 9. 可访问性

### 9.1 键盘导航

- Tab 键顺序：Desktop 图标 → Dock → 状态栏
- Enter 键：触发当前焦点元素
- Escape 键：关闭菜单

### 9.2 屏幕阅读器

```html
<div class="dock" role="toolbar" aria-label="应用任务栏" aria-orientation="horizontal">
  <div
    class="dock-icon"
    role="button"
    tabindex="0"
    aria-label="文件管理器"
    aria-pressed="false"
    onkeydown="handleKeydown(event)"
    onclick="handleClick()"
  >
    <div class="icon-container">📁</div>
    <div class="running-indicator" aria-hidden="true"></div>
  </div>
</div>
```

### 9.3 ARIA 状态

| 状态 | 属性 | 值 |
|-----|------|-----|
| 运行中 | aria-pressed | true/false |
| 指示灯 | aria-hidden | true（纯视觉） |
| 悬停 | aria-expanded | true/false（菜单）|
