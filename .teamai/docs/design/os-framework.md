## 🎨 设计原则

### Fluent Design 特性

1. **亚克力 (Acrylic)** - 半透明磨砂玻璃效果
2. **圆角设计** - 统一的圆角半径
3. **层级阴影** - 通过阴影区分层级
4. **悬停效果** - 微妙的交互动画
5. **流畅动画** - 所有状态变化平滑过渡

### 品牌特色

1. **神经网络连接** - Logo 元素融入界面
2. **智能感应** - 基于 AI 的上下文感知
3. **认知流** - 知识图谱的可视化流动

## 🔄 交互模式

### 桌面布局模式

**基础布局:**
- 侧边栏固定在左侧
- 主要内容区域占满剩余空间
- 任务栏固定在底部

**平板布局:**
- 侧边栏可收起
- 全屏应用时自动隐藏

**移动布局:**
- 侧边栏变为底部导航抽屉
- 任务栏与底部导航合并

### 应用窗口模式

**全屏:**
- 应用占满整个主工作区
- 可通过手势/快捷键调整

**窗口:**
- 可拖拽、调整大小
- 支持多窗口同时显示

## 📱 应用系统

### 内置应用

| 应用 | ID | 图标 | 描述 |
|------|----|------|------|
| 项目创建 | `app-project-create` | ➕ | 项目访谈与创建 |
| 文件管理 | `app-file-manager` | 📁 | 文件浏览器 |
| 本体管理 | `app-ontology` | 🕸️ | 知识图谱编辑器 |
| 设置 | `app-settings` | ⚙️ | 系统设置 |
| 帮助 | `app-help` | ❓ | 帮助文档 |

### 应用框架

每个应用作为独立的应用可：
- 添加到应用中心
- 从应用商店下载
- 固定到任务栏
- 卸载或删除
