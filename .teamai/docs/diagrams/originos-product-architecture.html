OriginOS 产品架构

业务访谈 → AI 解决方案规划 → 多 Agent 协作运行 — 从理解到交付的完整链路

Phase 1 · 业务访谈

  • • Interview Agent 引导式问答，理解用户业务
  • • Ontology 构建引擎在 5 秒内生成初始本体
  • • Domain → Concept → Instance 三层结构
  • • Ontology Skills 辅助推荐：领域/概念/关系
  • • 产出：本体图谱 + 访谈数据 (JSON)

Phase 2 · AI 解决方案规划

  • • Solution Design Agent 基于本体理解业务约束
  • • Agent 拓扑规划器定义角色、协作关系、DAG
  • • Solution Manifest 生成 (agents.json / skills.json)
  • • 协作拓扑图可视化 + 多版本方案对比管理
  • • 产出：可执行的 Solution Manifest

Phase 3 · 多 Agent 协作运行

  • • Collaboration Runtime 解析 Manifest 启动执行
  • • AgentSpawner 通过 npx tsx 启动子进程隔离
  • • Workflow (DAG) / System (Blackboard) 双模式
  • • 共享黑板 + 事件溯源 + HITL 人工审核
  • • 产出：Artifacts (文件/代码/文档)
