# SENSE.14 交互

连接详情分为消息状态和办公能力。未启用办公能力时保持原聊天体验；用户点击“启用能力”后选择真实支持的授权方式，显示授权账号及可访问范围，完成后显示能力清单。不要把App Secret或原始token展示在界面。

用户在群里说“把明天下午三点的评审加到我的日程”：Agent查找日程能力；若当前发言人没有委托授权，则说明需要绑定其账号，不擅自使用应用所有者日历。只有时间、时区、目标日历和参与人已明确且权限满足时执行，返回日程链接。缺失业务参数按需要澄清，不把内部SDK实现细节交给用户选择。

用户说“把这个事项建成待办”：按当前任务搜索工具、读取schema、调用平台；已有授权足够时直接执行，必要的确认复用现有HITL。成功后显示标题和链接；授权失效提示重新授权，限流提示稍后重试，创建超时结果不明提示正在核对／结果待确认，禁止称为已创建。

目录刷新只改变能力状态，不重置连接配置草稿、焦点或当前平台选择。多连接操作必须显示所选连接及执行账号；未绑定连接的本地会话先显式选连接，不能使用全局“最近活跃连接”。工具目录文字作为外部描述，不能覆盖Agent系统指令。
