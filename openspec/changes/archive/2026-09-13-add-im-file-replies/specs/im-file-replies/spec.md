## ADDED Requirements
### Requirement: 当前 IM 会话显式回传文件
系统 SHALL 提供 send_file 工具，将当前会话授权工作目录中的文件发回触发它的 IM 会话，并等待实际平台确认。
#### Scenario: 三平台普通文件
- **WHEN** 企业微信、飞书或钉钉会话内调用 send_file 指向受支持文件
- **THEN** 上传文件并发到原会话，确认后才返回成功
#### Scenario: 路径与大小
- **WHEN** 路径越界、符号链接逃逸、目录、空文件或文件超过20_000_000字节
- **THEN** 在平台上传前拒绝并显示明确错误
#### Scenario: 无上下文或调用结束
- **WHEN** 普通 UI 会话或已结束的 IM 调用尝试发送文件
- **THEN** 拒绝发送，不使用默认收件人或目录
#### Scenario: 并发会话
- **WHEN** 多个 IM 会话并发或同一会话串行排队
- **THEN** 每次发送保留各自工作目录和收件会话，不串发
### Requirement: 文件回复契约与失败可见
系统 SHALL 通过插件文件回复接口传递短期文件字节，不把文件内容持久化到聊天或投递回执中。
#### Scenario: 平台拒绝或发送未确认
- **WHEN** 上传、授权或发送失败或超时
- **THEN** 工具返回安全的失败结果，不谎报成功或盲目重发
#### Scenario: 成功重复调用
- **WHEN** 同一回复上下文及 toolCallId 的成功发送再次到达
- **THEN** 使用成功回执，不重复发送
#### Scenario: 旧插件
- **WHEN** 插件未显式声明文件回复支持
- **THEN** 不向该插件发送文件事件，原文本行为保持
### Requirement: 钉钉真实连接与文件回复
系统 SHALL 使用真实 Stream 连接和安全应用凭据，支持单聊与群聊文件回复。
#### Scenario: 首次绑定与连接
- **WHEN** 配置有效应用凭据并启用钉钉
- **THEN** 真实连接注册后显示健康，断开重连和停止均正确反映
#### Scenario: 接纳后确认
- **WHEN** 收到机器人消息
- **THEN** 事件安全落盘后及时确认，不等待 Agent 长任务结束
#### Scenario: 单聊与群聊
- **WHEN** 回传受支持文件
- **THEN** 群聊使用原 conversationId，单聊使用原 senderStaffId；无效用户或限流仍判失败
#### Scenario: 不支持的格式与停止
- **WHEN** 格式不受钉钉支持或连接已停止
- **THEN** 明确拒绝，停止后不遗留回复句柄或复活连接
