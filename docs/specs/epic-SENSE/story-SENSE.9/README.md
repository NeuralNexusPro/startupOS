# Story SENSE.9：感知中心产品入口

**状态：** Complete  
**Owner：** Product & Web  
**创建/更新：** 2026-08-28

## User Story

作为个人用户，我希望从首页打开「感知中心」，连接邮箱/企业微信/飞书/钉钉、配置触发规则并查看运行记录，以便无需理解底层 Connector 即可管理外部感知。

## 验收标准

- [x] 首页新增与应用启动器/项目/角色/技能平行的 Sense Center 顶层能力，并由 AppWindowManager 打开。
- [x] 包含感知源、触发规则、事件记录、运行状态四个视图。
- [x] 仅调用 SENSE.8 facade/API，不在组件或 Route 放业务逻辑。
- [x] secret reference 只输入或重新绑定，不回显。
- [x] 支持键盘、响应式布局和完整错误/空/加载状态。
